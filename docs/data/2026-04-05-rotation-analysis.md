# 2026년 4~5월 KBO 로테이션 분석

## 기준 데이터

- 4월 일정: `docs/data/2026-04-kbo-schedule.md`
- 4월 선발: `docs/data/2026-04-kbo-starters.md`
- 5월 일정: `docs/data/2026-05-kbo-schedule.md`
- 5월 선발: `docs/data/2026-05-kbo-starters.md`
- 분석 기준: 2026.04.01~2026.05.20 종료 경기
- 우천취소 경기는 실제 선발 기록이 없으므로 로테이션 이력에서 제외

## 결론

4월 데이터를 추가하니 단기 로테이션 예상 가능성은 더 높아졌다. 다만 팀별 차이가 크다.

MVP에서는 단일 정답형 예측보다 아래 구조가 적절하다.

```text
주 후보
보조 후보
휴식일
최근 등판 순번
변동 사유
```

## 알고리즘 시사점

1. 팀별 `로테이션 안정도` 점수를 따로 둬야 한다.
2. 최근 5경기만 보면 대체 선발에 속기 쉽다. 최근 10~15경기 또는 최근 30일을 같이 봐야 한다.
3. 선수별 선발 빈도와 최근 등판 간격을 함께 계산해야 한다.
4. 5번째 슬롯은 팀별로 특별히 낮은 신뢰도를 줘야 한다.
5. 우천취소는 실제 등판 이력을 남기지 않지만 다음 경기 순번을 밀 수 있으므로 일정 이벤트로 반영해야 한다.
6. UI에는 단일 이름만 크게 보여주기보다 `주 후보`, `변동 가능 후보`, `근거`를 함께 보여주는 편이 안전하다.
