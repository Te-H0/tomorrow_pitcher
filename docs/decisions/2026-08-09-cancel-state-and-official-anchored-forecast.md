# Cancel State, Blank-Actual Retry, and Official-Anchored Forecast

## Status

Accepted

## Date

2026-08-09

## Context

7/18~8/5 검증 데이터를 사후 분석한 결과 세 가지 문제가 확인됐다.

1. **실제 선발 공란 고착**: 경기가 `end`로 바뀐 직후 REVIEW 투수 기록이 게시되기 전에 수집하면 선발이 빈 값으로 기록됐고, "이미 기록된 gameId는 재접속하지 않음" 멱등 규칙이 빈 값을 영구 고착시켰다(7/19 5경기·7/21 4경기). 포인터 전진이 어제 실제 선발에 의존하므로 이 9건이 전 팀 `auto-hold` 연쇄 → 7/19~23 예측 붕괴(예고 대비 12.5%)의 직접 원인이었다.
2. **취소 경기의 비교 오염**: 취소 확정 경기의 예측 행이 `불일치`/`예고대기`로 남아 적중률 집계를 오염시켰다. 또 구 Model A 코드가 동결된 예측이 아닌 당일 재계산 예측과 예고를 비교해 기록한 오염 4행(20260722/0723 OBKT0)이 남아 있었다.
3. **취소·예고 정보 미활용**: 예고 선발은 관측 106건 전부 실제와 일치(100%)했는데도 포인터 교정에 쓰이지 않았다. 특히 8/5~8/9 연속 우천 취소로 전 팀 포인터가 8/4 상태에 고착 — 취소된 경기의 예고(= 그 투수가 여전히 다음 차례)를 버리고 있었다. D+1 이후 예측도 포인터 슬롯을 그대로 반복해 한 팀의 연속 경기일에 같은 투수를 예측했다.

## Decision

### 1. 선발 공란은 기록하지 않는다 (pending 재시도)

- `lib/review.mjs` `recordedIds`: 원정/홈 선발 중 하나라도 빈 행은 "기록됨"에서 제외 → 다음 수집/백필이 재시도한다.
- `extract-kbo-review.mjs`: end 경기의 REVIEW 선발이 빈 값이면 기록을 보류하고 pending으로 센다. 당일 저녁 회차의 빈 값은 정상(REVIEW 미게시)이지만, **익일 백필(yesterday)에서도 빈 값이면 DOM 계약 변경 의심으로 실패 처리**해 알림을 만든다(정상 수집분 저장 후 exit 1).
- `backfill-kbo-review.mjs`: 한쪽만 빈 경우도 실패 처리(기존은 양쪽 0행만).

### 2. 비교 컬럼에 `취소` 상태 도입

- 비교 값: `일치` / `불일치` / `예고대기` / `취소`. `취소`는 동결 상태이며 적중률 집계에서 제외한다. 예측 값 자체는 보존한다.
- forecast 실행 시 모든 `predicted/*.md`를 대상으로 취소 확정 gameId의 비교를 `취소`로 보정한다(멱등). 이 보정으로 Model A 시절 오염 4행도 함께 정리됐다(해당 경기 전부 취소).

### 3. 취소 경기 예고 기반 포인터 재정렬

어제 경기가 취소됐고 예고 투수가 로테이션에 있으면, 그 투수는 등판하지 않았으므로 **여전히 다음 차례**다. 포인터를 그 슬롯으로 재정렬한다(`auto-reanchor`, lastGame으로 멱등). 예고가 없던 취소는 기존대로 `auto-hold`.

### 4. 예고 반영 일자별 시뮬레이션 (D+1 이후 예측 개선)

오늘~D+N 예측을 포인터 고정값이 아니라 날짜 순서로 시뮬레이션 전진시킨다.

- 예고가 뜬 경기: 예고 투수 슬롯 기준으로 전진 (예고 = 하루 빠른 정답지).
- 취소 확정 경기: 예고 투수 슬롯 유지(전진 없음).
- 그 외 미래 경기: 예측 슬롯이 맞았다고 가정하고 전진(로테이션 순환 가정).
- 예고 투수가 로테이션에 없으면 유지(재정렬 보류와 동일한 철학).

효과: 한 팀의 연속 경기일에 서로 다른 투수를 예측하고, 예고 확인 즉시 D+2~3 예측이 자동 교정된다.

## Consequences

- 예측의 실질 가치 구간은 예고 전(D-1 낮 + D+2~3)이며, 비교는 예고 대조로 충분하다(예고=실제 100% 관측).
- `slots.md`가 로스터 변화(신규 외국인·콜업)를 따라가지 못하면 여전히 `auto-hold`가 쌓인다. 7/24 이후 실제 선발의 19%가 슬롯 밖 투수였다 — 등록/말소 연동과 관리자 확인 큐(관리자 페이지)가 다음 과제다.
- 연속 취소·휴식일 뒤 재개 첫날은 팀들이 로테이션을 재배치할 수 있어 신뢰가 낮다. 2026-08-09에 7/24~8/4 실제 + 8/5 예고 기준으로 `slots.md`/`pointers.md`를 수동 재시드했다.
